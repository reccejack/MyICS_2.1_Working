# MyICS-2.1
MyICS 2.1 builds upon the MyICS Project, building a mock industrial environment which will act as a home lab for computer networking, software development, IIoT, hardware and electronics integration.

Purpose:  
Establish a lab environment to demonstrate applied skills in software development, networking, microcontroller programming, and electronics. 
MyICS 2.1 will allow for further integration with additional IIoT and AI tooling.  

Objectives:  

1) Demonstrate the functionality of the MyICS Server software.
2) Establish the industrial control network between 'client' temperature gauges and the server.
3) Monitor temperature of a heated liquid medium and flag overheating.
4) Implement software-initiated fail-secure measures when specific thresholds are met.
5) Provide interface for IT integration with an OT environment.
6) Provide viable attack surfaces for penetration testing practical application.
